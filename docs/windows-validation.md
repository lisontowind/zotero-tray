# Windows 人工验证清单

先运行 `python scripts/run-windows-tests.py`。以下检查需要交互桌面或额外硬件，不包含在自动测试的通过项中。

使用 `python scripts/prepare-test-profile.py --install` 准备独立配置，再按脚本输出启动测试 Zotero。仅操作这个测试实例。记录 Windows/Zotero 版本、缩放比例、显示器布局和测试日志；测试后从托盘正常退出。

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| Explorer 真正重启 | 在可中断的测试桌面隐藏 Zotero，再通过任务管理器重启 Windows 资源管理器 | 图标自动恢复，点击能显示原窗口；若恢复持续失败，主窗口恢复可见 |
| 混合 DPI 多屏 | 使用不同缩放比例的显示器，将副屏置于主屏左侧或上方，在两屏任务栏分别打开菜单 | 菜单出现在点击位置，文字与行高适合所在屏幕；主窗口位置与大小保持不变 |
| 更改缩放 | Zotero 运行时改变显示器缩放，再打开托盘菜单 | 图标与菜单更新，反复操作无明显 GDI/USER 资源持续增长 |
| 休眠恢复 | 隐藏 Zotero，进入睡眠或休眠，恢复桌面后点击托盘 | 可正常显示窗口与打开菜单 |
| 故障通知 | 在测试驱动中注入 Worker 故障，点击 Windows 通知 | 主窗口可见；剪贴板中出现诊断 JSON；重复故障不会密集弹出通知 |
| 辅助功能 | 使用 Narrator，通过键盘选择托盘图标与菜单项 | 读出“显示 Zotero”和“退出 Zotero”，可通过键盘执行 |
| 外部集成 | 隐藏 Zotero 后使用浏览器 Connector 保存条目及 Word 插件插入引用 | 后台功能正常，必要时可恢复 Zotero；阅读器窗口关闭行为保持原样 |

Explorer 重启、休眠、注销和重启会影响整个桌面，请在可中断的测试环境操作。系统注销和重启检查应先保存工作，确认 Zotero 正常结束且不阻止退出。
