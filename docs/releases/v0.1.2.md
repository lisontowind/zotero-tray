# Zotero Tray v0.1.2

为 Windows 上的 Zotero 提供关闭到托盘、恢复和激活窗口、右键正常退出功能。

## 安装

下载本页附件 `zotero-tray-0.1.2.xpi`，在 Zotero“工具 → 插件 → 齿轮菜单 → 从文件安装插件”中安装。请先停用旧托盘插件，避免同时拦截窗口关闭。

已验证环境：Windows x64、Zotero 10.0.7；清单兼容范围限于 Zotero 10.0.x。当前版本通过下载新 XPI 手动更新。

## 功能与本版修复

- 关闭主窗口或 Alt+F4 后隐藏到托盘，最小化保持任务栏行为。
- 单击托盘图标或选择“显示 Zotero”：隐藏时恢复，已显示时请求前台激活，最小化时还原；保留窗口状态和几何信息。
- 右键“退出 Zotero”走正常退出流程，保留退出取消机制。
- 支持深浅色、高对比度及 DPI 缩放。
- 包含此前的图标生成性能优化和右键菜单重复弹出修复。
- 托盘初始化失败时保持窗口可见，禁用插件时恢复窗口并清理资源。

## 验证与安全

18 项 JavaScript 单元测试、可复现构建及纯源码包检查通过。独立 Zotero 测试配置中的 41 项集成检查通过，最终生产包安装、启动及正常退出验证通过。
