# Zotero Tray v0.1.4

本版改善异常资源回收，减少主题切换时的重复原生资源创建，并提供故障通知和 Windows 测试入口。

- 主线程 DLL 打开后立即登记，函数声明失败时也能回收。
- 原生清理最多尝试 4 次，失败后间隔 250 ms 重试；成功释放的资源不重复释放。持续失败时保留资源和回调引用。
- 菜单配色、字体和托盘图标分别更新，只切换菜单主题时复用字体与图标。
- 故障时显示非阻塞通知，点击 Windows 通知可复制诊断信息；持续清理失败时提示正常重启 Zotero。
- 增加原生资源失败路径测试、一键 Windows 集成测试脚本，以及 Windows/Linux CI 验证矩阵。手动原生 CI 需要已安装 Zotero 10 的 Windows 自托管运行器。

安装构建生成的 `zotero-tray-0.1.4.xpi`：Zotero“工具 → 插件 → 齿轮菜单 → 从文件安装插件”。自动更新需正式发布本版 XPI 及对应 `updates.json` 后生效。

已验证环境：Windows x64、Zotero 10.0.7。35 项 JavaScript 测试、2 项打包测试、46 项真实 Zotero 集成检查及正式 XPI 安装验证通过。源码和 XPI 的 Defender 扫描未发现威胁。

验证结果和设备限制见 [验证记录](https://github.com/lisontowind/zotero-tray/blob/v0.1.4/VALIDATION-0.1.4.md)。
