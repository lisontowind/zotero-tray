# Zotero Tray v0.1.3

本版完善发布信息、自动更新配置和异常清理，并减少后台轮询。

- 作者设为 `lisontowind`，补充 GitHub 项目主页和插件管理器图标。
- 更新入口指向 GitHub Releases 的 `updates.json`；构建时自动生成带下载链接、SHA-256 和兼容范围的清单。
- 停止等待最多 5 秒。清理未确认时恢复窗口、保留原生资源，延迟确认后完成释放；避免无限等待和强制终止原生回调。
- 消息泵由 30 ms 调整为 100 ms，健康检查由 2 秒调整为 10 秒；Explorer 重启通知会立即触发恢复，失败后每秒重试。
- 右键菜单采用托盘坐标，支持负坐标，并按所在显示器刷新 DPI。
- 增加版本标签校验和 GitHub Release 草稿工作流。

安装 `zotero-tray-0.1.3.xpi`：Zotero“工具 → 插件 → 齿轮菜单 → 从文件安装插件”。0.1.2 及更早版本使用占位更新地址，需要手动安装本版一次；后续自动更新以正式发布的 XPI 和 `updates.json` 附件为准。

已验证环境：Windows x64、Zotero 10.0.7。兼容范围保持 Zotero 10.0.x。25 项 JavaScript 单元测试、2 项打包测试和 43 项独立 Zotero 集成检查通过。源码和最终 XPI 的 Defender 扫描未发现威胁。测试结果和验证边界见 [验证记录](https://github.com/lisontowind/zotero-tray/blob/v0.1.3/VALIDATION-0.1.3.md)。
